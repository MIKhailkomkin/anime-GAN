# Модель для генерации изображений в стиле аниме с использованием GAN

## Описание проекта
Данный проект представляет собой генеративно-состязательную сеть (GAN) для создания изображений в стиле аниме. Архитектура модели включает энкодер-декодер, где энкодер сжимает входные данные в скрытое представление, а декодер восстанавливает изображения. Генератор и дискриминатор взаимодействуют для повышения качества создаваемых изображений.

## Основные возможности
- **Энкодер на основе CNN**: обработка входных данных и преобразование в скрытое пространство
- **Декодер для восстановления изображений**: преобразование скрытых представлений обратно в изображения
- **Генератор и дискриминатор**: использование GAN, где генератор улучшает качество изображений, а дискриминатор обучается отличать реальные изображения от сгенерированных
- **Обучение модели**: настройка процесса состязательного обучения для генерации реалистичных изображений в стиле аниме

## Установка и запуск
### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Предобработка данных
```bash
python scripts/preprocess.py
```

### 3. Обучение модели
```bash
python scripts/train.py
```

### 4. Генерация изображений
```bash
python scripts/generate.py --num_images 5
```

## Используемые технологии
- **Python**: основной язык разработки
- **PyTorch**: фреймворк для создания и обучения GAN
- **CNN (сверточные нейронные сети)**: энкодер и декодер для обработки изображений
- **Generative Adversarial Networks (GAN)**: состязательное обучение генератора и дискриминатора
